# Declara-fast

## Overview

Declara-fast is an Excel spreadsheet project designed to help organize personal information and financial documents for Brazilian Income Tax Return preparation.

The project was developed as a practical exercise in spreadsheet organization and data management.

## Features

- **Taxpayer information:** Organizes personal information in a dedicated worksheet.
- **Financial information:** Provides a worksheet for organizing bank statements and financial amounts.
- **Income and expense records:** Includes a worksheet for recording entries, categories, and values.
- **Information organization:** Brings relevant information together to make document preparation easier.

## Workbook Structure

| Worksheet | Purpose |
|---|---|
| Titular | Organizes taxpayer information. |
| Informes | Organizes financial information and reported amounts. |
| Notas | Records entries, categories, and values. |

## How to Use

1. Download the Excel file from this repository.
2. Open it using Microsoft Excel or a compatible spreadsheet application.
3. Fill in the relevant fields with your own information.
4. Review the information entered and use the spreadsheet to help organize the documents needed for tax preparation.

## Tools and Concepts

- Microsoft Excel
- Spreadsheet organization
- Data management
- Structured information entry

## Limitations

This spreadsheet is intended to support information organization. It does not replace official Brazilian tax filing systems, professional tax advice, or verification of applicable tax rules.

The information entered should be checked for accuracy before being used to prepare a tax return.

## Project Goal

To apply spreadsheet skills to a practical problem involving personal finance, document organization, and structured data entry.
